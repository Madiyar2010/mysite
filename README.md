# 🏰 Замок Героев

Семейная 3D-игра в браузере со звуком и музыкой. На телефонах и планшетах играется горизонтально. Играйте вместе с телефонов, планшетов и компьютеров — каждый со своего устройства.

## Режимы
- ⚔️ **Каждый сам за себя** — кто больше выбьет соперников за 3 минуты
- 🔴🔵 **Команда на команду** — первые до 15 очков
- 🚩 **Захват флага** — принеси флаг врага на свою базу (до 3)
- 💀 **Все против монстров** — 6 волн скелетов, зомби, вампиров и призраков, в конце босс
- **Найди предателя (как Among Us)** — карта «Космическая станция» на 14 комнат: задания с мини-играми, саботажи (свет, двери, реактор, кислород, связь), люки, камеры, админ-стол, роли (шериф, инженер, учёный, ангел-хранитель, оборотень), собрания с чатом и голосованием, все настройки лобби

Классы: 🛡️ Рыцарь, 🏹 Лучник, 🔮 Маг, 🥷 Ниндзя. За игры дают монеты — в магазине шапки и ауры.

## Как играть
1. Один игрок нажимает «Создать комнату».
2. Остальные открывают сайт и вводят код из 4 букв (или сканируют QR).
3. Хост выбирает режим и жмёт «Играть».

Управление: на телефоне — джойстик пальцем и кнопки справа; на компьютере — WASD, мышь, пробел.

## Техника
- Чистый HTML/JS без сборки, [Three.js](https://threejs.org/) для 3D, [PeerJS](https://peerjs.com/) для связи устройств (WebRTC).
- Хост считает игру, остальные шлют ему действия.
- Хостинг: любой статический (например, GitHub Pages).
