# Замок Героев

Семейная 3D-игра в браузере со звуком и музыкой. На телефонах и планшетах играется горизонтально. Играйте вместе с телефонов, планшетов и компьютеров — каждый со своего устройства.

## Режимы
**Шутер** (вид от 1-го или 3-го лица, переключается кнопкой):
- Каждый сам за себя · Команда на команду · Захват флага · Все против монстров (6 волн и босс)
- Раунды с закупкой без возрождения или игра на время с возрождением — выбирает хост
- 12 видов оружия трёх стилей: обычное (пистолет, пистолет-пулемёт, автомат, дробовик, снайперка), бластеры (лазерный пистолет, плазмомёт, рельсотрон), игрушечное (водяной пистолет замедляет, пейнтбол метит врага, снежкомёт), плюс гранаты, броня, аптечка, нож
- 4 карты:
  - «Склад» — контейнеры в два этажа, мостик, ворота по таймеру, погрузчики, которые толкают
  - «Замок» — зал с решётками, которые открываются по очереди, качающиеся маятники, стены с бойницами
  - «Ночное кладбище» — склепы с решётками, алтарь, скелеты встают из могил и нападают на всех
  - «Городская улица» — дома и магазины, в которые можно зайти, по дороге ездят грузовики
- Боты трёх уровней
- На телефоне: помощь в прицеливании и автострельба (выключаются в настройках), чувствительность обзора

**Найди предателя (как Among Us)** — 3 карты по 14 комнат: «Космическая станция», «Замок с призраками» (своя планировка, задания и саботажи вроде «Свечи погасли» и «Ядовитый туман»), «Подводная база» (затопление вместо утечки кислорода). На каждой: задания с мини-играми, саботажи (свет, двери, реактор, кислород, связь), люки, камеры, админ-стол, роли (шериф, инженер, учёный, ангел-хранитель, оборотень), собрания с чатом и голосованием, все настройки лобби

## Как играть
1. Один игрок нажимает «Создать комнату».
2. Остальные открывают сайт и вводят код из 4 букв (или сканируют QR).
3. Хост выбирает режим и жмёт «Играть».

Управление: на телефоне — левый палец ходит, правый смотрит, кнопки справа; на компьютере — WASD, мышь, пробел, R, G, B, V.

## Техника
- Чистый HTML/JS без сборки, [Three.js](https://threejs.org/) для 3D, [PeerJS](https://peerjs.com/) для связи устройств (WebRTC).
- Хост считает игру, остальные шлют ему действия.
- Хостинг: любой статический. Для Vercel: Add New → Project → выбрать этот репозиторий → Framework Preset «Other», без команды сборки → Deploy. Настройки кэша — в `vercel.json`.
